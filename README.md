# CS-Silver-Studded-Blue
A blue-yellow colourblind friendly theme for CS

# dependancies
- stylus extention which you can find for [chrome](https://chromewebstore.google.com/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne) or [firefox](https://addons.mozilla.org/en-GB/firefox/addon/styl-us/)
- [tampermonkey](https://www.tampermonkey.net/) or [violentmonkey](https://violentmonkey.github.io/) to use accompanying userscript
